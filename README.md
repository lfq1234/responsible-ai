## 课程与章节映射

| 作业 | 对应章节 | 核心主题 |
|------|----------|----------|
| TASK1 | 第一章 | 负责任人工智能导论：生命周期、支柱、监管、职业责任 |

### TASK3 — 公平性实践

| 文件 | 说明 |
|------|------|

**任务要点**（第三章"公平性实践"案例研究的拓展）：
- A 部分——车险定价：问题一 MDP 的 lambda 扫描（lambda ∈ {0, 0.25, 0.5, 0.75, 1} 的 DIR/RMSE）；问题二 仅对 Density 去偏；问题三 为何仅靠无意识不够（代理性歧视）；问题四 部署建议（推荐 MCDP）
- B 部分——COMPAS 分类：问题五 roc_pivot 的 theta 扩展扫描（新增 theta = 0.25 / 0.30）；问题六 不存在满足所有准则的 theta（基准率差异下的不可能性）
- 实现：Python 3.12（statsmodels / xgboost），DI remover 与 roc_pivot 严格对照 fairmodels/fairness R 包源码复刻，结果与讲义完全一致

### TASK4 — 可解释性原则

| 文件 | 说明 |
|------|------|
| `作业4可解释性原则.pdf` | 题目（含概述、说明与五道问题） |
| `林富强_作业4.docx` | 完成稿（可编辑 Word 版） |
| `林富强_作业4.pdf` | 完成稿（PDF 版） |
| `build_作业4.py` | 作业4生成脚本（Python，可复现排版） |

**任务要点**（第四章"可解释性原则"，延续 TASK1 的软件缺陷预测系统场景）：
- 问题一：高风险决策（发布门禁）需要可解释性 vs 低风险决策（重构建议）不需要；公共福利之外领域（缺陷预测标记）的托育丑闻式失败
- 问题二：三类利益相关方（模型验证人员 / 工程负责人 / 被评估开发者）的解释范围与方法映射；为何单一方法无法满足
- 问题三：PFI 排序作为新模型第一项诊断；相关变量（LOC 与圈复杂度）单独打乱的误导性
- 问题四：PDP 外推与取平均两项弱点如何被对抗性利用（Xin 2025）；子群体效应差异下 PDP vs ICE
- 问题五：解释权/监管举证场景推荐 SHAP（TreeSHAP）；改用 LIME 的具体风险
