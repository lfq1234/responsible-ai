# Responsible AI — 负责任人工智能课程作业

本仓库用于存放《负责任人工智能：原则、治理与量化方法》（黄斐，新南威尔士大学）课程作业的题目与完成稿。

## 目录结构

```
responsible-ai/
├── LICENSE
├── README.md            # 本文件：项目总览
├── TASK1/               # 第一次作业：负责任人工智能导论
└── TASK2/               # 第二次作业：公平性原则
```

## 作业清单

### TASK1 — 负责任人工智能导论

| 文件 | 说明 |
|------|------|
| `作业1负责任人工智能导论.pdf` | 题目（含概述、说明与四道问题） |
| `林富强_作业1.docx` | 完成稿（可编辑 Word 版） |
| `林富强_作业1.pdf` | 完成稿（PDF 版） |

**任务要点**：
- 选取软件缺陷预测系统作为应用场景
- 问题一：负责任人工智能六阶段生命周期
- 问题二：公平性与非歧视、隐私与数据伦理两大支柱的应用
- 问题三：中国监管路径比较
- 问题四：反思——负责任 AI 是职业责任而非仅技术责任

### TASK2 — 公平性原则

| 文件 | 说明 |
|------|------|
| `作业2公平性原则.pdf` | 题目（含概述、说明与四道问题） |
| `林富强_作业2.docx` | 完成稿（可编辑 Word 版） |
| `林富强_作业2.pdf` | 完成稿（PDF 版） |
| `build_作业2.py` | 作业2生成脚本（Python，可复现排版） |

**任务要点**（考核第二章"公平性框架"前两步：界定公平性、设计公平模型）：
- 问题一：自动化招聘筛选中的直接/间接歧视（单选 + 简答）
- 问题二：车险高风险标记系统的混淆矩阵计算（标记比例、PPV、TPR、FPR，检验 DP/分离性/充分性）
- 问题三：五种模型设计（M0 / MU / MDP / MCDP / MC）与监管干预类型的配对
- 问题四：致首席精算师的公平性方案备忘录（200–300 字）
